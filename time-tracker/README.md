Time Tracker

Десктопный таймер для Windows и macOS в тёмной теме. Считает время от 00:00:00 без ограничений, ведёт календарь, задачи и цели.

Возможности
Таймер от 00:00:00 до бесконечности. Продолжает идти, даже если закрыть программу или выйти из аккаунта.
Аккаунты (логин и пароль, без защиты). У каждого аккаунта свои данные.
Календарь: дни, когда работал таймер, подсвечены зелёным и показывают часы. При наведении на дату видны время и названия задач. К любой дате можно добавить заметку и выделить её любым цветом.
Список задач: название вписывается перед стартом или выбирается из списка, записи за день можно править и удалять.
Неделя: круговая диаграмма по задачам с процентами, при наведении видны часы. Под ней столбики по дням.
Цели: лимит часов на задачу в неделю, в месяц или за всё время, с полосой прогресса.
Автообновления через GitHub Releases.
Установка

Готовые установщики лежат в разделе Releases или в артефактах последней сборки на вкладке Actions.

Windows: запустите .exe. Если появится окно SmartScreen, нажмите «Подробнее», затем «Выполнить в любом случае».

macOS: откройте .dmg и перетащите приложение в «Программы». При первом запуске нажмите на него правой кнопкой и выберите «Открыть». Если система всё равно блокирует запуск, откройте «Системные настройки», затем «Конфиденциальность и безопасность» и нажмите «Всё равно открыть». Для Mac с чипом Apple (M1 и новее) берите файл с arm64 в названии, для Intel — без него.

Приложение не подписано, поэтому система показывает предупреждения.

Где хранятся данные

Всё хранится локально в одном файле timetracker-data.json и никуда не отправляется:

Windows: %APPDATA%\time-tracker\
macOS: ~/Library/Application Support/time-tracker/

При обновлении программы данные сохраняются.

Запуск из исходников

Результат появляется в папке dist. Каждый установщик удобнее собирать на своей системе.

Сборку можно запустить и на GitHub без установки чего-либо на компьютер: вкладка Actions, затем Build installers, затем Run workflow. Готовые файлы будут в разделе Artifacts завершённого запуска.

Выпуск новой версии
Увеличьте version в package.json (например, 1.0.1).
На GitHub создайте релиз с тегом v1.0.1 (раздел Releases, затем Create a new release).
Сборка запустится сама, и установщики прикрепятся к релизу.

Приложение проверяет обновления через 5 секунд после запуска и затем раз в 4 часа.

Windows: обновление скачивается само, внизу слева появляется кнопка «Перезапустить».
macOS (без платной подписи Apple): приложение показывает «Доступна версия X» и открывает страницу загрузки.

Автообновления работают только в собранном приложении, а не при npm start.

Технологии

Electron, чистые HTML, CSS и JavaScript, electron-builder и electron-updater.
